# AFTERMATH Frontend
Evidence-Backed AI Security Regression Lab. React (JavaScript) + Vite + Tailwind, React Router, @xyflow/react, Recharts, react-hot-toast.

Runs entirely in the browser with local sample data (`src/services/demo.js`). There is no backend or API code. Sample results are synthetic and labelled DEMO; they are not real security results.

```
npm install
npm run dev
npm run build
npm run preview
```
Data is held in memory, so a refresh resets it. Not implemented: scenario editing, run cancellation, batch runs, report export.
